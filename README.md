# 喵遊台北／東京 Taipei & Tokyo Cat Walker

> 當一隻貓，在台北與東京的大街小巷散步。

一款以 [three.js](https://threejs.org/)（r128）打造的 3D 網頁散步遊戲。整個遊戲就是**一個 HTML 檔**，不需要安裝、不需要打包，用瀏覽器打開就能玩。電腦和手機都能玩。

## 特色

- **兩座城市**：台北、東京，開始畫面或設定裡都能切換。
- **六種貓咪花色**：橘貓、黑貓、賓士貓、白貓、虎斑貓、三花貓。
- **真實路名**：走到哪條路，左上角就會出現對應的路名牌和行政區（台北是綠色路名牌，東京有日文招牌）。
- **熱鬧的街景**：騎樓、招牌、霓虹燈、行道樹、停在路邊的機車，還有紅綠燈和來來往往的車流（台灣靠右開、日本靠左開）。
- **高架鐵路**：台北有文湖線（復興南北路），東京有山手線。
- **可以點的地圖**：點小地圖打開大地圖，點任何一個地方或地標，貓咪就會直接過去。
- **貓的小動作**：喵喵叫、跳上機車和郵筒；站著不動一會兒會坐下、趴成吐司，最後睡著打呼嚕。

## 怎麼玩

直接用瀏覽器（建議用最新版 Chrome、Safari、Edge 或 Firefox）打開 `喵遊台北／東京.html`，選好城市和貓咪，按下開始就可以了。

> 需要網路連線：three.js 和字型（Noto Sans TC／JP、Huninn）是從 CDN 載入的。

### 設定

右上角的「設定」可以：

- 切換城市（會回到開始畫面）
- 更換貓咪花色
- 開關即時影子（關掉會比較順）
- 開關街上的車子
- 開關喵叫與喇叭聲

設定會存在瀏覽器的 `localStorage`（`taipei-cat-settings`），下次打開時自動套用。

## 程式結構

所有程式碼都在同一個 HTML 檔的 `<script>` 裡，依區塊分段（在檔案中搜尋區塊標題就能跳過去）：

| 區塊 | 內容 |
| --- | --- |
| [1] | 工具函式、亂數（固定種子，每次生成的城市都一樣） |
| [2] | 世界狀態與地圖註冊表 `MAPS` |
| [2a] | 地圖：台北 `MAPS.taipei` |
| [2b] | 地圖：東京 `MAPS.tokyo` |
| [3] | 貼圖、材質、合併幾何（效能用） |
| [4] | 碰撞系統 |
| [5] | 城市生成：街廓、巷弄、建築、招牌、行道樹、機車／腳踏車 |
| [6] | 地標共用零件（廟宇、鳥居、塔…） |
| [7] | 環境：地面、水岸、遠景、天空、高架鐵路 |
| [8] | 車流與紅綠燈 |
| [9] | 貓咪：模型、動畫、移動 |
| [10] | 攝影機、輸入、介面、小地圖、音效 |
| [11] | 載入地圖（切換城市）與主迴圈 |

座標系統：x 向東為正，z 向南為正（北方是 -z），y 向上。

### 新增一座城市

每座城市都是 `MAPS` 裡的一份「地圖定義」。想加新城市的話，照著 `MAPS.taipei` 或 `MAPS.tokyo` 複製一份，再修改以下內容：

- 名稱、主題色、字型、開始畫面的招牌文字
- `setup()`：用 `ew()`（東西向）和 `ns()`（南北向）畫道路，設定範圍並加入地標
- `districtAt()`：依座標回傳行政區名稱
- `fronts`／`lands`／`water`：水岸與陸地
- `rail`：高架鐵路
- `traffic`：車流數量與車子顏色
- `features`：街景特色（騎樓、行道樹、自動販賣機…）
- `heightRule()`：建築高度規則
- `buildEnv()`：遠景（山、遠方建築）
